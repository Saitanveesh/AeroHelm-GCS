# AeroHelm — upstream provenance, copyright and distribution

AeroHelm is a project built **on an existing open-source native ground-control foundation**, with new cloud fleet architecture, transport, identity and operator-workspace work developed separately. Public presentation must credit both the original software and original project-specific engineering.

## Inherited foundation

The native application tree, solution and build structure in `master` derive from **[ArduPilot Mission Planner](https://github.com/ArduPilot/MissionPlanner)**. Mission Planner is an ArduPilot ground-control application and is **not** authored solely by the AeroHelm repository owner.

The inherited license text is in [`COPYING.txt`](../COPYING.txt), **GNU General Public License version 3**. This file and the underlying copyright notices must remain intact. Changes to README copy or a new AeroHelm identity cannot remove the rights and obligations attached to this upstream code.

Other bundled components may be distributed under additional license terms. Review source headers and `ExtLibs/` license files, NuGet assets and any third-party binaries when building/releasing a distributable package.

## AeroHelm-specific work

The AeroHelm-specific development represented by the separate GitHub branches includes cloud fleet models, scoped operator/device identity, mission/lease orchestration, virtual workers, telemetry uplink, C# touch/links UI experiments and associated tests and runbooks. Ownership of an individual contribution follows its actual authorship and any applicable licenses—not the name on a GitHub repository alone.

**Maintainer:** Sai Tanveesh / [Saitanveesh](https://github.com/Saitanveesh), for original AeroHelm contributions to the extent owned.

Source files, native plugins and other derivative additions distributed together with GPL-covered ground-control code may be subject to GPL-3.0 obligations. Standalone separately deployed cloud components require their own licensing/dependency analysis; **no blanket claim that the entire AeroHelm system can be relicensed at will** is made.

## Redistribution checklist

- Preserve original copyright notices, COPYING, attributions and any legally required license text.
- Identify modified source accurately and make GPL-covered corresponding source available when GPL distribution obligations apply.
- Check each bundled third-party library or asset for compatibility and notice/redistribution requirements.
- Do not present upstream executable download links or CI badges as independently certified AeroHelm releases.
- Review dependencies, exported artifacts, proprietary components and embedded SDKs before licensing a distribution.
- Do not commit flight controller credentials, access tokens, private network routes, full personal log files or aircraft-identifying secrets.
- Perform a legal review before making commercial exclusivity or proprietary redistribution claims involving the inherited native GCS code.

## Safety and authenticity

No source/binary release generated by this documentation change is a signed flight-certified artifact. Flight-controller command authority is a distinct safety matter; neither the AeroHelm logo nor a plugin login screen grants permission to control an aircraft.
